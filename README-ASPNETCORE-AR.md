# Tester — ASP.NET Core 8
هذه حزمة تحويل أولي للخادم من Node.js إلى ASP.NET Core 8، مع الاحتفاظ بواجهة HTML وجداول PostgreSQL الموجودة.

## نشر Render
- نوع الخدمة: Docker، وDockerfile في جذر المستودع.
- المتغيرات المطلوبة: DATABASE_URL وJWT_SECRET (سلسلة عشوائية 32 بايت أو أكثر)، وADMIN_USER وADMIN_PASSWORD (12 حرفًا أو أكثر لإنشاء المسؤول لأول مرة).
- Health check: /api/health
- لا تضع كلمات السر في GitHub. لا تنشر قبل اختبار البناء والوظائف.

## حدود النسخة
- تدعم تسجيل الدخول، إدارة العملاء والجداول، إنشاء جلسات الاختبار وتسجيل نتائجها، عرض التقارير كـ JSON، وعزل بوابة العميل.
- لم تُنقل بعد صادرات PDF/Excel/PowerPoint ولا التعديل الكامل على المستخدمين ولا محركات الاختبار التلقائي.
- لم يُنفذ dotnet build في هذه البيئة لعدم توفر .NET SDK؛ لذلك لا يمكن ضمان البناء أو النشر قبل الاختبار.
- لا تُغيّر الخدمة المنشورة إلى هذا الإصدار قبل نجاح البناء والتحقق من التوافق.
